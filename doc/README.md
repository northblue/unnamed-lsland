## 当前可玩内容

| 系统 | 已实现 |
| --- | --- |
| 探索与建造 | 扩大的沙滩 / 草地 / 草坡 / 高地 / 山丘 / 沙丘，层叠岩坡与石阶，移动与碰撞，木石采集 / 漂流物收集，小屋预览与推荐空地 |
| 钓鱼 | 岸边抛竿，从浮标附近实际游过的小鱼中随机钓获，分类鱼篓、24 条容量海边观赏鱼池；四类海鱼及鱼池使用骨骼动画模型，双语近距离观察页 |
| 昼夜 | 现实 24 小时或 60 / 24 / 12 分钟一天，时间预览、油画太阳 / 月亮，细星点与 ✨ 星芒闪烁、仙后座 / 猎户座 / 南十字座 |
| 海岸生态 | 透明海水、风浪 / 岸浪、果冻晃动 / 水花，开放路线鱼群与大型海洋访客，带羽翼骨骼的小鸟 / 海鸥拍翼、滑翔与停栖，细化灯塔光束、鲸鱼偶尔跃水、海豚 / 海豹巡游、沙滩海螺 / 螃蟹 |
| 树木与声音 | 资源树逐步再生，精细椰子树 / 阔叶树 / 伞状树冠混排、分层风摆、雾状轻云与球形天空边界，可选合成海风 / 浪声 / 鸟鸣，默认静音 |
| 岛上景点与伙伴 | 层叠灯塔高地、石阶 / 木平台 / 守塔小屋，海边半场篮球场、大向日葵，3 只猫与 3 只狗自主追逐、游荡、玩耍和休息；景点镜头快捷按钮 |
| 存档与管理 | 本地 D1 自动保存岛名、材料、资源点、玩家位置、建筑、鱼篓和鱼池；管理面板可改岛名、材料与建筑 |
| 界面 | 中文 / English，镜头旋转、缩放、俯视 / 斜俯视 / 侧视，窄屏面板折叠、专注小岛一键隐藏 / 恢复菜单 |

本地当前仍采用 Wrangler 模拟 D1（底层 SQLite）；NAS 使用共享 PostgreSQL，各项目独立库 / 账号。NAS 基线迁移和 Mac 旧岛导入 / 校验已成功，局域网首页、health、存档接口均实际返回 200，仍共用当前岛屿。共享密码入口已实现并通过 CI 临时 PostgreSQL / 登录 / 重启验收，认证镜像已由用户在 NAS 启用，公网经 Tunnel 的未登录跳转已实测；main 自动发布与 NAS 更新器已通过 CI，用户已确认 NAS 更新器运行，日志重复显示当前版本 UP TO DATE；不等同于个人账号系统。离线试玩不保存；昼夜速度、预览和声音开关是会话设置，语言偏好单独保存在浏览器。

最近功能改动通过 73 项游戏测试、21 项服务端测试和 Next.js 生产构建；这不代表完成了跨设备性能、音质或生产验证。具体范围见开发进度。当前操作仍以桌面键鼠为主，窄屏排版不代表已有完整手机触控控制。

## 协作方式

保持小步可玩，规则与 Three.js 外观分离，数据库只在服务端访问。新文案集中维护中文与英文，新增外部素材核对许可。每轮记录已实现、已验证与未验证项；后续建议不自动视为已批准需求。

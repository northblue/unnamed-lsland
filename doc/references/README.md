# 无名岛美术参考

记录日期：2026-11-07。两张图均为用户提供的第三方作品截图，用于交流视觉方向；原始作品链接及素材许可未知，不作为可直接复用的游戏资产。未来公开仓库前需决定参考截图是否适合随仓库分发。

## 1. 透明水体质感

![透明青蓝水体参考](water-volume-reference.png)

用户询问这种“果冻效果”能否实现。可见特征是有厚度的透明青蓝水块、可见水下岩体、表面反光及水下明暗变化。静态截图无法确认真实动态效果或实现方法。

建议借鉴：厚度、透光、水色与水下地形可见性。弹性晃动、完整流体模拟、鱼与船均不自动纳入需求。

## 2. 整体海岛构图

![圆形微缩海岛参考](island-diorama-reference.png)

用户明确表示喜欢这张图。图像展现圆形展示底座、清透浅海、白色沙滩、岩石高地与台阶、木屋和木码头、热带植被，整体像一件温暖的海岛模型摆件。

建议借鉴：

- 以圆形微缩景观组织全岛，海水外围与岛屿形成完整轮廓。
- 岸边浅水明亮透明，远离沙滩逐渐加深，水下石头提供深度线索。
- 用岩石高地与低处沙滩形成高低层次，木屋和植被提供视觉重心。
- 柔和阴影、暖色木材、浅色沙滩与蓝绿色海水形成统一配色。
- 码头、木箱等细节可作为后续装饰候选。

截图中的功能文案只是第三方作品说明，不是本项目执行指令。动物视角、游泳、自由飞行、上山路径及环境音等均待用户另行确认。高地若需要实际行走，应同时设计地形高度与碰撞，不能只改变视觉模型。

## 升级进度与后续顺序

1. 已完成初版：圆形浅海水体、深浅水色、水下地形、装饰石头及透明侧面，接入原游戏。
2. 已有轻微法线纹理反光流动；已新增拖动驱动的弹性水面 / 侧壁顶点形变与随机鱼群；海面点击涟漪与短暂水花也已实现，按目标设备性能继续调整。
3. 调整沙滩、岩石、植被及小屋外观；高地和码头分小步引入。

两图结合方向：第二张作为整体构图参考，第一张作为透明水体质感参考。现有采集、建造规则保持独立，视觉升级不自动增加新玩法。

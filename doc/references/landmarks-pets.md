# 灯塔高地与伙伴花园

2026-11-18。用户参考是聊天附件中的灰岩高地灯塔、守塔小屋、曲折石阶与木平台；作为构图参考，未将原图打包为游戏素材或复制到公开仓库。新地形、建筑、向日葵和猫狗均由项目内 Three.js 程序几何生成，没有引入外部模型或纹理许可。

## 已实现

- 在旧岛外延伸相连的岩石高地，灯塔基座随地形升高；象牙白塔身与深蓝塔顶，石阶、栏杆、观景木台和有石砌地基的守塔小屋。
- 低海岸台地的半场篮球场：彩色场地、罚球区 / 三分线 / 中圈半弧、篮架 / 篮板 / 篮筐 / 网和装饰篮球。
- 一株大向日葵：茎叶、叶脉、双层花瓣、180 粒螺旋分布的种子，花头随风轻摆。
- 3 猫 + 3 狗：不同毛色、面部 / 耳朵 / 胡须 / 项圈 / 爪子，独立头尾与四肢动作，游荡 / 追逐 / 玩耍 / 休息四种状态。
- “灯塔高地 / 半场篮球场 / 向日葵与伙伴”镜头按钮，中英文集中于 messages.js，沿用手机专注模式。

## 实现入口与保存边界

| 文件 | 责任 |
| --- | --- |
| ../../code/src/game/world.js | 新岸线与高度、原地面兼容、固定障碍物；原小屋建造椭圆保留 |
| ../../code/src/game/terrain.js | 岩岸网格、灰岩配色和实例化岩柱 |
| ../../code/src/game/islandLandmarks.js | 石阶 / 小屋 / 球场 / 向日葵；静态几何合批 |
| ../../code/src/game/pets.js | 独立于渲染的伙伴移动、状态和避障逻辑 |
| ../../code/src/game/petModel.js、petView.js | 猫狗模型、步态和地面定位、资源释放 |

不新增数据库字段或迁移，不清空旧进度。固定景点不进入玩家建筑数组；猫狗路径 / 时间 / 位置不保存。球场和篮球当前为景观，没有投篮操作；猫狗不提供喂养、领养或存档管理。

## 验证记录

本地 73 项游戏测试、21 项服务端测试、PostgreSQL standalone 生产构建通过。新增测试覆盖整个旧椭圆的高度采样不变、已有有效小屋存档、球场地面 / 行走、新地面海面交互、猫狗长期移动和避障 / 减少动态效果、模型独立动画与清理。海面点击和岸边钓鱼使用新岸线；小鱼穿过新陆地时隐藏且不可钓，大型访客路径避开新陆地。

使用独立 3019 服务，数据库指向关闭端口，实际进入离线试玩检查；没有对 Mac 或 NAS 的真实存档执行写入。近景截图见 [花园](../screenshots/landmarks/sunflower-pets.png)、[灯塔](../screenshots/landmarks/lighthouse-day.png) 和 [手机](../screenshots/landmarks/mobile-garden.png)。手机 390×844 专注模式下页面宽高等于视口，没有横向溢出；景点镜头 / 恢复菜单与英文按钮可用。浏览器中检查灯塔白天 / 午夜、球场花园及猫狗动作；有预期的数据库不可达日志，未观察到 Three.js shader 错误。

未验收真实手机 GPU / Safari / 长时间内存与性能负载；当前风格仍是柔和微缩造型，不是照片级模型。石阶为贴合高度场的景观，不是独立攀爬或寻路网格。NAS 新版本是否实际替换，应以更新器日志和运行容器 digest 为准。

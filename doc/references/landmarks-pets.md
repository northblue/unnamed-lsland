# 灯塔高地与伙伴花园

2026-11-18。用户参考是聊天附件中的灰岩高地灯塔、守塔小屋、曲折石阶与木平台；作为构图参考，未将原图打包为游戏素材或复制到公开仓库。地形、建筑、向日葵为项目内程序几何。猫狗初版为程序模型，后续按用户要求升级为带纹理和骨骼动画的 [Mesh2Motion 模型](pet-models.md)，程序模型保留为失败回退。

## 已实现

- 在旧岛外延伸相连的岩石高地，灯塔基座随地形升高；象牙白塔身与深蓝塔顶，石阶、栏杆、观景木台和有石砌地基的守塔小屋。
- 低海岸台地的半场篮球场：彩色场地、罚球区 / 三分线 / 中圈半弧、篮架 / 篮板 / 篮筐 / 网和可交互篮球。
- 一株大向日葵：茎叶、叶脉、双层花瓣、180 粒螺旋分布的种子，花头随风轻摆。
- 3 猫 + 3 狗：不同毛色、面部 / 耳朵 / 胡须 / 项圈 / 爪子，独立头尾与四肢动作，游荡 / 追逐 / 玩耍 / 休息四种状态。
- “灯塔高地 / 半场篮球场 / 向日葵与伙伴”镜头按钮，中英文集中于 messages.js，沿用手机专注模式。
- 向日葵缩为初版 52%，白天随太阳灯光转向，夜间花头降低并朝下；猫狗缩小、螃蟹缩为原版 45%。玩家空格跳跃，不能在空中再次起跳，水平碰撞继续生效；跳跃状态不保存。
- 沙滩连续向水下渐降，替换旧围边；薄浪贴合浅滩，建造和存档地面高度保留。

## 验证记录

首版 73 项游戏测试、21 项服务端测试、PostgreSQL standalone 生产构建通过；后续比例 / 素材 / 跳跃 / 追日 / 沙滩通过 80 项游戏测试与 21 项服务端测试，最终生产镜像状态见 progress.md。测试覆盖整个旧椭圆高度采样、已有有效小屋存档、球场地面 / 行走、新地面海面交互、猫狗长期避障、真实 GLB 骨骼与独立动画 / 减少动态效果 / 清理、跳跃帧率一致性和无二段跳、追日方向 / 夜间垂头、沙滩连续下降。海面点击和岸边钓鱼使用新岸线；小鱼穿过新陆地时隐藏且不可钓，大型访客路径避开新陆地。

使用独立 3019 服务，数据库指向关闭端口，实际进入离线试玩检查；没有对 Mac 或 NAS 的真实存档执行写入。近景截图见 [花园](../screenshots/landmarks/sunflower-pets.png)、[灯塔](../screenshots/landmarks/lighthouse-day.png) 和 [手机](../screenshots/landmarks/mobile-garden.png)。手机 390×844 专注模式下页面宽高等于视口，没有横向溢出；景点镜头 / 恢复菜单与英文按钮可用。浏览器中检查灯塔白天 / 午夜、球场花园及猫狗动作；有预期的数据库不可达日志，未观察到 Three.js shader 错误。

未验收真实手机 GPU / Safari / 长时间内存与性能负载；当前风格仍是柔和微缩造型，不是照片级模型。石阶为贴合高度场的景观，不是独立攀爬或寻路网格。NAS 新版本是否实际替换，应以更新器日志和运行容器 digest 为准。

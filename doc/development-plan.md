# 无名岛当前规划与实现边界

更新：2026-11-16。本文是当前方案，阶段历史与验证证据见 [开发进度](progress.md)，启动方式见 [应用 README](../code/README.md)。

## 1. 已确认方向

- 名称：无名岛 / Unnamed Island；包名 `unnamed-island`。
- 技术：Next.js App Router + JavaScript + Three.js，应用在 `code/`。
- 当前数据库实现：Prisma + D1，本地由 Wrangler 模拟 SQLite。已选择 NAS 共享 PostgreSQL，各项目独立数据库 / 账号，复用现有 Tunnel。UGREEN 用户日志确认 PostgreSQL 17.12 服务已启动，两个项目库 / 所属角色、vector 0.8.7 及 mind_app TCP 登录已确认；隔离已有截图 / 用户检查反馈，第一次逻辑备份与当前空库的非覆盖恢复演练成功，真实业务数据 / 完整重启回归待验证，小岛已加入可选 PostgreSQL 接入和独立基线迁移，CI 临时 PostgreSQL 读写 / 冲突 / 重启验收已通过，GHCR Web / tools 镜像已发布；NAS 已由用户完成应用启动 / 基线迁移且 health 200，Mac 旧岛实际导入 / 校验及局域网 HTTP 访问已通过；共享密码已在 NAS 启用，公网 Tunnel 的未登录跳转已实测，登录后的公网读写待现场验收，见 [共享数据库部署](../deploy/postgres/README.md)。
- 体验：明亮柔和的微缩海岛，单人桌面键鼠优先，逐步学习和实现；当前没有饥饿死亡、战斗或其他惩罚机制。
- 发布：main 源码推送自动测试 / 构建并发布已验证 nas-stable；NAS 通过一次性安装的独立更新器更新 Web，健康失败回退，数据库结构变更需人工迁移。更新器 CI 已通过，NAS 启用待现场操作。
- 核心循环：探索 → 采集 → 建造 → 保存；钓鱼与自然景观作为已确认的扩展内容。

不在当前范围：种植、天气、造船、多岛屿、多人、复杂背包、鱼饵制作、烹饪 / 交易、繁殖 / 喂养与完整手机触控。鸟类和大型海洋访客已有装饰表现，不代表这些玩法已实现。

## 2. 当前规则与参数

### 世界、移动与建造

| 项目 | 当前实现 |
| --- | --- |
| 陆地 | 椭圆半轴 X=20、Z=15.5；较上一版 15×11.5 面积增加约 80% |
| 外海 | 圆形半径 33；视觉、海面交互、鱼群路线与钓鱼校验使用共享参数 |
| 地形 | 西侧高地、北部山丘、东侧坡地、南侧沙丘及 3 处礁石；上一版 15×11.5 内保留原高度，最初 12×9 内保持 Y=0.52 |
| 移动 | WASD / 方向键随镜头换算，斜向归一化，角色按地形高度行走 |
| 资源 | 12 棵树、4 块可采大石，每处 3 次、每次 1 份，交互范围 1.8 |
| 小屋 | 消耗 6 木材 + 3 石料，占地半宽 1.4、半深 1.2，固定朝向 |
| 放置校验 | 完整占地在陆地、避开角色 / 有效资源 / 礁石 / 装饰树 / 鱼池 / 建筑，占地采样高差不超过 0.35 |

资源树采完后约 180 秒可见页面在线时间逐步再生，进度保存在资源 JSON 的 growth 秒数中，刷新继续；暂停管理或隐藏页面时不推进，不受昼夜加速影响。石料资源点仍不再生；海上漂流物可持续补充木石。树未成熟不可采集、不阻挡行走或建造；房屋覆盖处暂停再生，角色站在树位时推迟成熟。耗尽的树桩 / 碎石不阻挡行走或建造；房屋覆盖的残留装饰隐藏。岸边装饰小石不可采集。原资源坐标和稳定 ID 保留，旧地形平坦范围保留，扩岛没有清空旧存档。

小屋支持推荐空地、鼠标预览和确认按钮，预览与提交使用同一规则。材料不足时保持探索，不进入暂停采集的建造模式；成功建造只扣一次材料。尚无建筑旋转、室内、睡眠或升级功能。

### 漂流物与岩岸层次

海上最多 6 件漂流物缓慢靠岸，木板 +2 木材，物资箱 +1 木材 / +2 石料。角色 8 单位内，可按 E、点击物件或通过“海岸物资与树木”按钮收集；探索时 E 优先收集附近漂流物。每件只奖励一次，约 100 秒路线周期结束后随机再来；最初两件已靠岸方便试玩。路线 / 物件状态不保存，刷新会重建；所得材料正常保存。

岩坡增加灰色石层、贴坡岩柱和上山石阶，保持 terrainHeight 与已有建筑地面高度。台阶和岩柱为地形外观，不是新增建筑或攀爬物理，也不代表已复刻参考图的木屋、码头或船。

### 钓鱼

免费使用鱼竿。靠岸后按 F / 按钮进入瞄准，点击海面抛竿；辅助按钮只从当前在范围内的小鱼中选择目标，无鱼时提示等待或换海岸。

- 抛竿距离不超过 13 单位；只有浮标附近 3.4 单位内实际游过的小鱼参与判定。
- 最早 0.6 秒后开始，每 0.8 秒有候选鱼时有 55% 机会随机钓到一条；最多等待 25 秒，可能空竿。
- 上钩自动收鱼。瞄准时可移动，等待时原地持竿，镜头仍可操作；F / Esc 取消，切换建造或打开管理也会结束钓鱼。
- 金色、蓝色、珊瑚、银色四类对应当前鱼群颜色。钓到的成员从本次经过的鱼群中消失，鱼群离开再进入时才补充新成员。
- 鲸鱼、海豚、章鱼和鸟类不可钓获。鱼篓分类数量持久保存；鱼群路线、浮标及钓鱼中间状态不保存。

四类海鱼群与鱼池已使用 Quaternius Fish1 / Fish2 / Fish3 骨骼模型和颜色变体，并有跟随头部骨骼的眼睛；模型加载失败回退原外观。不改变 ID、鱼种分类、路线或钓获规则。钓鱼面板的“近距离观察小鱼与海鸟”打开 /fish-preview，可选择四种鱼、两种鸟外观，旋转缩放，对照原程序鱼，或切换拍翼 / 停栖；不访问存档。素材与转换记录见 references/animal-models.md。

### 海边鱼池

新岸线固定石砌鱼池位于 X=16、Z=6，半径 2.1，免费使用，最多 24 条。展开钓鱼面板中的“海边鱼池”，按鱼种点击“放入 / 取回”，每次转移 1 条。可以远程通过面板管理，无需角色走近；放入仅消耗现有鱼篓中的鱼，取回返还同种鱼，不增加总量。鱼池中显示对应颜色和数量的小鱼游动，不繁殖、不喂养，也无材料配方或自由放置功能。

鱼池范围阻挡角色和建筑，池底有独立浅盆地，水面透明。pond.js 管转移与容量规则，pondView.js 管石圈 / 水 / 小鱼，pond JSON 与鱼篓在同一次带 revision 的存档更新中保存。旧存档缺少该字段时补空鱼池。

### 昼夜与自然景观

默认跟随设备本地时间；可选择 60 / 24 / 12 分钟一天。加速比例切换从当前显示时刻继续，选现实模式同步设备时间。加速时钟在页面隐藏时暂停，不用移动步长的上限计算时间。

滑杆与日出 / 正午 / 日落 / 午夜按钮提供静态预览；结束预览恢复所选时钟，预览期间加速时钟继续推进。速度和预览是会话设置，刷新恢复现实模式，不改变存档或玩法资源。

天空采用《星月夜》意象的不规则蓝色流云与旋涡、颜料颗粒笔触、柔和金色星光和暖黄色月亮，白天保持圆形太阳，借鉴《向日葵》的金黄 / 赭黄厚涂画风；夜空通过 sky.js 加载项目内油画贴图，太阳叠加透明背景的圆形厚涂日轮贴图，加载失败回退程序日轮，沿用昼夜与减少动态效果设置。天空为屏幕空间的贴图与程序日月组合，配合环境光、太阳 / 月光和水体反光变化；不是基于经纬度、季节、月相或真实星图的天文模拟。海水有透明侧壁、渐变海床、基础风浪、岸边白浪、拖动果冻回弹及点击涟漪 / 水滴，不是完整流体物理。

椰子树（细分弯曲树干、生长环 / 纹理、三层独立风摆羽叶、叶鞘与五枚椰子）、阔叶树和伞状树冠混排，资源树保持原 ID / 采集 / 生长状态；分枝树干与树冠随风摆动；扩出的区域另有 10 棵不可采集的装饰树，参与碰撞与鸟类栖息；5 只小鸟和 5 只海鸟会飞行，部分选择仍存在的树枝 / 礁石栖息，树被采掉后飞离。普通小鸟夜间休息，海鸟夜间隐藏。鸟类不参与碰撞或存档。减少动态效果偏好下关闭树冠摆动、浪纹推进、拍翼和星星闪烁，仍保留场景和鸟类位移。

海风、海浪和鸟鸣通过 Web Audio 合成，默认静音，由用户点击开启；页面隐藏暂停音频。夜空与圆形油画太阳使用内置 image_gen 生成的厚涂油画位图（来源与提示词见 references/fine-stars-explorer.md 和 references/oil-sun-asset.md），四类小鱼与鱼池使用 Quaternius CC0 骨骼模型，小鸟 / 海鸥采用 Mesh2Motion CC0 鸟类及 Flap / Glide / Idle 动画（references/animal-models.md）。鸟的方向跟随实际位移，滑翔 / 拍翼 / 停栖平滑混合，暖棕小鸟与白色海鸥比例不同；鲸鱼 / 海豚使用同包 CC0 骨骼模型；海豹 / 海螺 / 螃蟹 / 椰子树为本项目程序模型，音频继续合成。来源与范围见 references/marine-tropical-upgrade.md。

## 3. 当前操作

| 操作 | 输入 / 入口 |
| --- | --- |
| 移动 | WASD / 方向键；点击画面恢复键盘焦点 |
| 采集 | 靠近资源按 E；长按不重复采集；附近漂流物可按 E / 点击收集 |
| 建造 | 集齐材料后“放置小屋” → 推荐空地 / 自选位置 → 确认；Esc 取消 |
| 钓鱼 | F / 面板开始，点海面或“朝附近鱼群抛竿”；F / Esc 退出 |

| 镜头 | 拖动旋转、滚轮缩放；建造时右键旋转；按钮切换预设 |
| 水花 | 探索时单击海面；拖动和建造点击不触发普通水花 |
| 时间 | 时间面板选择速度、滑杆和预览；不是调节系统时间 |
| 声音 | 管理按钮下方环境声音开关，默认关闭 |
| 存档编辑 | “管理岛屿”修改岛名、木石数量、建筑坐标及增删建筑，保存并应用 |
| 语言 | 中文 / EN，切换不重建场景，尝试本地记住偏好 |
| 专注小岛 | 一键隐藏大部分面板，再点“显示菜单”恢复；窄屏首次默认简洁模式，浏览器记住手动选择 |

管理编辑不扣配方材料，仍校验数量、坐标、碰撞和地形。没有一键重置功能；此前规划中的二次确认重置仍是待办。

近岸灯塔为固定景观，位于西侧独立礁石，范围不与可建造 / 可行走陆地重叠。昼夜系统驱动灯室、暖色光晕与聚光灯的亮度，夜间缓慢扫光，减少动态效果时静止；礁石不接受抛竿与水花。地形视觉采用平滑法线与柔和草岩配色，圆润岩块贴合西坡，保留既有高度函数和旧存档地面。光束细化为柔边外层与亮芯、距离渐隐和轻微雾感变化；仍不增加灯塔建造配方、升级或数据库字段。

海水采用单层透明表面与 512×512 平面反射，按视角混合、水下深度着色；移除原两层屏幕透射，绘画天空不进入镜面相机。保留弹性、水花和鱼群规则；平面反射增加一次场景绘制，尚未量化性能。鲸鱼在海域中段偶尔进行约 4.2 秒跃水，分别触发起跳 / 落水水花；减少动态效果时不跃水。保留海豚并加入独立海豹，访客均不可钓获。沙滩海螺和四只螃蟹为装饰，不增加采集 / 捕捉或存档字段。

夜空当前使用 oil-night-small-stars-v2.png，去除大金色星团，保留蓝色油画旋涡；贴图上方独立叠加细星点、少量四角星芒 / 伴星与慢速错峰闪烁，月亮保持明显圆盘。减少动态效果时固定星光时间。人物由 explorerModel.js 构建精细程序模型与四肢关节，行走 / 持竿只影响表现；FishingView 使用实际右手握点，存档仍只保存 player 的 x / z。模型观察页支持人物站立 / 行走。

星光增加冷白 / 暖色主星、柔光与轻微独立闪烁，淡线标示仙后座 W 形、猎户座腰带三星和南十字座，名称跟随界面语言。宽屏显示三组，竖屏仅在下方空白油画背景显示猎户座 / 南十字座以避开面板；白天隐藏，减少动态效果时静止。这是简化艺术构图，不是按地点、季节或时间计算的真实星图；原油画背景和月亮继续保留。细节与截图见 [星座记录](references/constellations.md)。

天空增加半径 33、底圈与海面衔接的透明上半球边界；边缘仅淡淡高光，无碰撞或折射物理。七组云使用面向镜头的半透明雾片和程序噪声，沿直线路线穿过球形空间，在最后 4 单位逐渐消隐，路线重置发生在球外；昼夜 / 黄昏改变云色，减少动态效果时静止。四只海鸥也沿跨球路线飞入 / 飞出，原五只小鸟与一只海鸥保留栖息。云、穹顶、鸟群片元共用同一球形范围；穹顶 / 云 / 岸浪不进入平面反射，不保存位置。沙滩近岸薄水层贴合岸唇，细泡沫缓慢推进、消散并带轻微水光；减少动态效果时冻结。均为装饰景观，未增加天气、云层体积模拟或新采集物。椰叶小叶与叶轴按三层合批，层间独立轻摆，资源树的 ID、树高、采集 / 生长和鸟类栖息规则保留。详见 [球形天空记录](references/sky-volume.md)。

### 存档与数据库

存档 version 当前为 1，包含岛名、木材、石料、资源点剩余量 / 树木生长秒数、玩家 XZ、建筑列表、分类鱼篓和鱼池。尚无 worldVersion 字段。玩家高度由地形推导，恢复位置不合法时选择安全可走位置。

Island 是当前实际使用的单岛记录；资源点、建筑、鱼篓和鱼池为 JSON，与材料数量一起在单条 id + revision 条件更新中原子保存，防止旧页面覆盖新存档。缺少鱼篓或鱼池字段的旧存档可解析为空集合。User / GameSave 是未接入登录流程的模型草案。

本地采用 OpenNext + Wrangler D1 模拟器，SQLite 数据位于 `code/.wrangler/state/`；无需 DATABASE_URL 或 PostgreSQL。旧生产方案为独立 D1；最新 NAS 方向已改为共享 PostgreSQL，待改驱动和迁移存档，当前应用仍沿用 DB binding + PrismaD1。Prisma 客户端按请求创建，不跨请求缓存 Worker binding。迁移使用 `migrations/0001_island_persistence.sql` 、`0002_fishing_catches.sql` 和 `0003_seaside_pond.sql`，由 Wrangler 执行，不用 Prisma migrate dev / deploy 或 db push 操作 D1。

API 当前仅开放 localhost，固定一个开发岛屿，没有认证或每用户存档。生产 database_id 为本地占位值，未创建、绑定或迁移真实生产库，未部署。公开前需认证、归属校验、真实生产配置及 Workers 预览验证。

| 状态 | 保存方式 |
| --- | --- |
| 岛名、材料、资源耗尽、角色 XZ、建筑、鱼篓、鱼池 | 本地 D1，变化后约 1 秒检查保存 |
| 中文 / 英文偏好 | 浏览器 localStorage，失败不阻止切换 |
| 昼夜速度、时间预览、声音开关 | 当前会话，刷新恢复默认 |
| 动物 / 漂流物路线、浮标、水花、风浪形变 | 不存档 |

连接失败显示错误，用户可主动选择不保存的离线试玩；不会用空进度静默覆盖原存档。写入失败可重试，revision 冲突需要保留修改并刷新最新数据。
